# Goals

## Core Game
- Create a retro pixel-art Kaiju autobattler.
- Player builds and modifies a Kaiju in a laboratory.
- Battles are mostly automatic.
- Kaiju moves through 2.5D scrolling levels.
- Enemies attack throughout the level.
- Each level ends with a boss.

## Progression
- Defeated enemies provide resources.
- Kaiju returns to the laboratory after battle.
- Player can replace organs and body parts.
- Builds should allow very different playstyles.

## Design Goals
- Battles should last roughly 2–5 minutes.
- Player decisions happen primarily before battle.
- Runs should encourage experimentation with builds.
